1️⃣ OBTÉN LAS 5 IPS:

   En cada máquina:
   Linux/Mac: hostname -I
   Windows: ipconfig | findstr "IPv4"

   Ejemplo:
   Redis:  192.168.1.100
   Srv-A:  192.168.1.101
   Srv-B:  192.168.1.102
   Srv-C:  192.168.1.103
   Agente: 192.168.1.104

2️⃣ INSTALA DEPENDENCIAS EN TODAS:

   pip install flask redis requests --break-system-packages

3️⃣ MÁQUINA REDIS:

   Instalar:
   - macOS: brew install redis
   - Linux: sudo apt-get install redis-server
   - Windows: descarga desde github

   Configurar:
   - Editar /etc/redis/redis.conf
   - Cambiar: bind 127.0.0.1 → bind 0.0.0.0
   - Guardar: Ctrl+X → Y → Enter

   Ejecutar:
   redis-server

4️⃣ MÁQUINA SERVER-A:

   Copiar:
   - server_redis_MODIFICADO.py (renombrar a server_redis.py)
   - config_SERVER_A.py (renombrar a config_A.py)

   Editar config_A.py:
   REDIS_HOST = "192.168.1.100"  # TU IP REAL

   Terminal 1:
   python3 server_redis.py

   Terminal 2:
   ngrok http 5000

  ERRORES COMUNES

❌ "Connection refused"
✅ Verifica que Redis está corriendo: redis-cli PING

❌ "Connection timed out"
✅ Verifica IP es correcta: ping 192.168.1.100

❌ "No hay servidores en Redis"
✅ Verifica config_*.py tiene IP correcta
✅ Verifica redis.conf: bind 0.0.0.0
