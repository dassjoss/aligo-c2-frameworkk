│                                                                     │
│  1. Server generates RSA-2048 keypair on startup                   │
│                                                                     │
│  2. Agent: GET /public-key                                         │
│     ↓                                                               │

│                                                                     │
│  3. Agent generates Fernet session key (32 random bytes)           │
│                                                                     │
│  4. Agent encrypts session key:                                    │
│     encrypted_key = RSA-OAEP-SHA256(session_key, server_pub_key)  │
│                                                                     │
│  5. Agent: POST /checkin                                           │
│     Body: {"encrypted_session_key": "<base64>", ...}              │
│     ↓                                                               │
│     Server: Decrypt session key with RSA private key              │
│     Server: Store in agents[agent_id]['session_key']              │
│                                                                     │
│  ✅ Encrypted channel established!                                 │
└─────────────────────────────────────────────────────────────────────┘

│  COMMANDS (Server → Agent):                                        │
│    1. Operator types: use @agent whoami                            │
│    2. Server encrypts: Fernet(cmd_json, agent_session_key)        │
│    3. Server sends: {"payload": "<encrypted_base64>"}             │
│    4. Agent decrypts: Fernet-decrypt(payload, agent_session_key)  │
│    5. Agent executes command                                       │
│                                                                     │
│  RESULTS (Agent → Server):                                         │
│    1. Agent executes command                                       │
│    2. Agent encrypts: Fernet(result_json, agent_session_key)      │
│    3. Agent sends: {"payload": "<encrypted_base64>"}              │
